# Support

Matryca Trama is an early public foundation. Please search existing issues and documentation before opening a new request.

- Use GitHub Discussions or a public issue for questions, usability feedback, and feature proposals.
- Use a non-confidential Discussion for commercial-licensing interest; no
  commercial price or right is granted until a separate written agreement is
  executed.
- Use a bug issue for a reproducible defect, including the revision and a minimal sanitized example.
- Use [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose them publicly.

Do not attach private vaults, credentials, procurement details, or unredacted
logs. A small synthetic graph is preferred. State whether the question concerns
Logseq OG, Logseq DB, the shared contracts, Nodi, or commercial licensing.
