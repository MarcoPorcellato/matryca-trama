# Synthetic Graph Demo Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans.
> Direct-main execution is selected; primary implements, Astra Medium reviews.
> Steps use checkbox syntax; actual status and evidence are tracked in local

**Goal:** Deliver an offline, navigable fictional graph as Trama's first visible
demo, reusing LENS visualization work without source access.

**Architecture:** A fixture-only gateway composes existing Trama graph values.
A presentation projection adds invented labels; a browser view renders it
with locally bundled vis-network. Python builds a standalone HTML artifact;
an optional loopback preview serves only that artifact.

**Tech Stack:** Python 3.12+, standard library, existing Trama core, plain
JavaScript/CSS, official vis-network 9.1.2 UMD bundle; Node built-in test runner.

**Spec:** [Synthetic graph demo design](../specs/2026-10-26-synthetic-graph-demo-design.md).

## Review Focus

- Filtering removes selected nodes: clear stale selection and dangling edges.
- Empty results and isolated nodes: useful message and usable reset/neighbor UI.
- Labels with HTML/script text: literal display, no markup execution.
- Mobile/keyboard/reduced motion: full navigation without canvas pointer use.
- Offline/source boundary: no outbound request, graph access or producer launch.

## Observed implementation evidence

Astra Medium approved the design before implementation. The final source
review found a hidden narrow-screen source status and lost keyboard focus
after the starting action. Both failures were reproduced and corrected;
scoped re-review returned PASS on tree
`7da069efd1f8920e8e40a7b69f9b15aedd210ae1`.

The ordinary regression passed 253 Python tests and five Node state tests.
Focused demo tests passed again after the review fixes. Browser verification
covered desktop, 390px mobile and 900px tablet, visible source status,
keyboard focus, search and filters, node/neighbor navigation, empty/reset,
zoom, offline HTML navigation and literal hostile-label tooltips, with zero
page errors and zero external requests. Generated HTML, screenshots and the
compact browser result remain ignored local build artifacts; Beads records
actual source-publication status. No MA, producer or real-graph operation was
performed. This evidence does not establish performance or source compatibility.
