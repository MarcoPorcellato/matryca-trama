# ADR-0011: Synthetic graph demo composition

Status: Accepted for the owner-authorized synthetic demo after Astra Medium
design review (PASS_WITH_NOTES), 2026-10-26.

The owner requested an autonomous implementation after that review. Admit the
scoped application described in the [design](../superpowers/specs/2026-10-26-synthetic-graph-demo-design.md),
without changing package directions, source-admission records or R1–R5
producer proposals. This is the first fictional presentation, not a supported
Logseq application or a released runtime.

Use existing immutable core values and its gateway port with a built-in
fictional provider. Keep labels, categories and personal/work membership in
presentation annotations. The fixture provenance identifies itself as
synthetic, never as a Plumber artifact. The browser consumes a Trama demo view,
not copied owner schemas or wire semantics.

Reuse LENS's renderer family and interaction ideas; do not copy Parser source
extraction code. Admit the official standalone vis-network 9.1.2 UMD asset,
SHA-256 `3729be2f3994c83229106c3d34fb8de807572cf6f282c23e2b34ecf4e84ce863`,
under its offered MIT option with upstream headers and license files retained.
This is a third-party asset dependency; Trama-owned material remains PolyForm
Noncommercial. The external-contributor agreement hold is unchanged.

The canonical [standard](../standards/CLEAN_ARCHITECTURE.md) defines precise
builder and loopback-preview exceptions. Use safe text/JSON, hashed script CSP
without unsafe-eval, no outbound requests and a fixed generated artifact. Add
app-specific boundary checks because the existing validator scans packages.
No package map, lock, qualification input or qualification workflow changes.

No MA, producer, comparator, real-graph or native DB operation is authorized.
Ordinary tests and browser functional verification exercise fictional data
only. Broader consumer admission and programme completion remain separate.
