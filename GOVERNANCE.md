# Governance

Matryca Trama is maintained as a public source-available Community foundation
for a calm, local-first Logseq sidecar.

## Decision principles

Maintainers prioritize user safety, native source authority, Logseq OG/DB interoperability, deterministic behavior, accessibility, clear contracts, and a useful Community foundation. Product ideas must respect the separate Matryca Brain boundary and must not require private implementation access.

## Changes

Small documentation and maintenance changes may be reviewed directly once the
contributor licensing gate permits their merge. Cross-cutting behavior, public
API, licensing, security, pricing commitments, or repository-boundary changes
should include an architecture decision record and maintainer review. The issue
and pull-request history is the public record of decisions.

## Roles

Contributors propose and review changes within the contribution rules.
Maintainers are responsible for repository policy, releases, security response,
commercial licensing, and final acceptance. Maintainer decisions should be
explained in the relevant issue or pull request.

## Scope

This repository governs the public Trama Community foundation. It does not
govern private Matryca Brain implementation, private user vaults, or independent
upstream projects such as the Parser and Plumber repositories.
